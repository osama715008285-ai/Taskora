\# Taskora — Smart Student Planner



Taskora is a smart academic task management web application built with Flask, SQLite, HTML, CSS, and JavaScript.



It helps students organize academic tasks, prioritize important work, track deadlines, and monitor productivity.



\## Features



\- Add academic tasks

\- Edit existing tasks

\- Delete tasks

\- Mark tasks as completed or active

\- Smart priority scoring

\- Priority levels:

&#x20; - Urgent

&#x20; - High

&#x20; - Medium

&#x20; - Low

\- Search tasks

\- Filter tasks by:

&#x20; - All

&#x20; - Active

&#x20; - Completed

\- Deadline tracking

\- Due Today detection

\- Overdue task detection

\- Next deadline display

\- Productivity percentage

\- Progress tracking

\- Smart task recommendation

\- Responsive design for:

&#x20; - Desktop

&#x20; - Laptop

&#x20; - Tablet

&#x20; - Mobile

\- Toast notifications

\- Custom delete confirmation

\- SQLite database persistence



\## Technologies Used



\- Python

\- Flask

\- SQLite

\- HTML5

\- CSS3

\- JavaScript
